# Skyscraper Stack Repair Lab

A Pygame precision timing and balance game where the player stacks
moving blocks to build the tallest possible skyscraper.

## Overview

The game features:

-   Horizontally moving blocks that bounce across the screen
-   Precision block placement using Space or left mouse click
-   Automatic block trimming based on overlap
-   Perfect placement bonuses
-   Falling off-cut debris animation
-   Dynamic camera scrolling as the tower grows
-   Atmospheric background progression as the tower gets taller
-   Game Over and instant restart functionality

## Requirements

-   Python 3.10+
-   Pygame

## Installation

Create and activate a virtual environment:

``` bash
python3 -m venv venv
source venv/bin/activate
```

Install Pygame:

``` bash
pip install pygame
```

## Running the Game

From the project root:

``` bash
python3 main.py
```

## Implemented Tasks

### Task 1: Fix Inverted Overlap Placement

The original placement condition was inverted. Successful placement now
requires a positive horizontal overlap between the active block and the
block below it.

-   `overlap > 0` → successful placement
-   `overlap <= 0` → tower collapse

### Task 2: Perfect Placement Bonus

When the active block is aligned within a small horizontal tolerance of
the previous block:

-   The block snaps into alignment.
-   Its full width is preserved instead of being trimmed.
-   A `PERFECT!` popup is displayed.
-   Bonus score is awarded.
-   Consecutive perfect placements are tracked.
-   After three consecutive perfect placements, the block width is
    slightly restored/expanded.

A normal placement resets the perfect-placement streak.

### Task 3: Falling Off-Cut Debris

When a block is trimmed because of partial overlap, the removed overhang
is represented as a separate debris object.

The debris:

-   Falls using gravity.
-   Has its own velocity.
-   Rotates while falling.
-   Is removed after moving sufficiently far off-screen.
-   Supports multiple debris objects at the same time.

### Task 4: Atmospheric Background Progression

The background changes as the tower grows instead of remaining a flat
dark grey.

The sky progresses through different atmospheric stages, including:

-   Twilight blue
-   Dusk purple
-   Night/starfield
-   Dark stratosphere

The transitions are based on tower height and are smoothly interpolated.
The starfield is maintained without regenerating random stars every
frame.

## Project Purpose

This project was completed as part of a Vibe Coding lab. The
implementation was developed iteratively with an LLM used as a debugging
and pair-programming assistant.

The completed project demonstrates:

-   1D bounding-box intersection
-   Dynamic geometry slicing
-   Object-oriented game architecture
-   Physics-style debris animation
-   Vertical camera scrolling
-   Progressive difficulty
-   Dynamic rendering and background transitions
